# FLOW sticker artwork

Drop your real sticker PNGs in this folder using the exact filenames below.
Each one replaces its themed placeholder automatically — no code changes needed.
Square images (1:1, e.g. 1000×1000) on a transparent or light background look best.

| `flow-jurassic.png`     | FLOW Park                       | Jurassic Park       |

`_placeholder/` holds the auto-generated stand-in SVGs shown until the matching
PNG exists. You can leave it as-is.
